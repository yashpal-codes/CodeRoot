### Grid is CSS display property

- CSS has standard algorithm called Flow layout and other are like Table layout and Flexbox layout.
- Grid is most advanced and useful from all of them.
- In Grid a single DOM node is divided into rows and column, into other for every row a DOM element is added.
- By default CSS grid uses a single Column and rows are created as needed based on number of children.
